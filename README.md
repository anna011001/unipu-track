# UNIPU Track

Web application for managing university records and reports.

## Technologies

### Frontend
- Vue 3
- Vite
- Vuetify

### Backend
- Node.js
- Express.js
- PostgreSQL

## Project structure

- `frontend` – Vue application
- `backend` – Express REST API
- `database` – PostgreSQL schema

## Local setup

### Database

createdb unipu_track
